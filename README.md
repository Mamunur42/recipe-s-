# Odin Recipes 🍽️

Welcome to my **Odin Recipes** project!

This is a beginner-friendly HTML project created as part of my journey through [The Odin Project](https://www.theodinproject.com/).

## 📌 About the Project

Odin Recipes is a simple recipe website built using HTML. It contains links to different recipe pages.

## 🍳 Recipes Included

- Lasagna Recipe
- Noodles Recipe
- Ilish Curry Recipe

## 🛠️ Technologies Used

- HTML5

## 📂 Project Structure

```text
odin-recipes/
│
├── index.html
│
└── recipes/
    ├── lasagna.html
    ├── noodles.html
    └── IlishCarry.html
```

## 🎯 What I Learned

Through this project, I practiced:

- Creating HTML boilerplate.
- Using headings, paragraphs and lists.
- Adding links between web pages.
- Organizing files and folders.
- Using Git and GitHub for version control.
